# Python - Async Functions

## Description

This project introduces asynchronous programming in Python. It explores coroutines, concurrent execution, task creation, and execution time measurement using the `asyncio` module.

## Learning Objectives

- Understand asynchronous functions and coroutines.
- Use `async` and `await`.
- Execute multiple coroutines concurrently.
- Measure the execution time of asynchronous operations.
- Create and manage `asyncio.Task` objects.
- Retrieve results in the order in which tasks complete.

## Tasks

| Task | Description |
|---|---|
| `0-basic_async_syntax.py` | Define an asynchronous function that waits for a random delay. |
| `1-concurrent_coroutines.py` | Execute multiple asynchronous operations concurrently. |
| `2-measure_runtime.py` | Measure the average execution time of concurrent coroutines. |
| `3-tasks.py` | Create an `asyncio.Task` from a coroutine. |
| `4-tasks.py` | Execute multiple tasks concurrently and collect their results. |
